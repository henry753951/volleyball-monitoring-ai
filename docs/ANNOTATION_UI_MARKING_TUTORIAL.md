# 標記 UI 操作教學

這份教學協助第一次使用標記工作站的人，在影片中快速完成一個回合的基本標記。

## 你會完成什麼？

1. 找到回合開始的位置
2. 標記球員接觸球的時間點
3. 找到回合結束的位置
4. 選擇結果並送出標記

## 介面區域

| 區域       | 用途                             |
| ---------- | -------------------------------- |
| 影片播放器 | 播放、暫停與確認畫面中的動作     |
| 時間軸     | 移動到回合開始、接觸與結束的位置 |
| 標記控制列 | 建立回合、加入接觸、選擇結果     |
| 回合狀態   | 顯示目前是草稿、處理中或已完成   |

## 基本操作

### 1. 找到回合開始

播放影片，或用方向鍵逐格尋找回合開始的畫面。

按下 `Z` 建立回合開始標記，再繼續往後尋找回合結束位置。

> `Z` 只代表回合的開始/結束邊界，不代表發球、接球或落地事件。

### 2. 標記接觸球

當球員接觸球的瞬間出現在畫面中時，按下 `X` 加入一次接觸標記。

如果同一回合有多次接觸，將影片移到每個接觸瞬間，分別按下 `X`。

### 3. 結束回合

找到回合結束的畫面後，再按一次 `Z` 建立回合結束標記。

### 4. 選擇回合結果

使用以下按鍵選擇結果：

| 按鍵 | 操作           |
| ---- | -------------- |
| `<`  | 判定左方結果   |
| `>`  | 判定右方結果   |
| `?`  | 暫時記錄為未知 |

結果是回合的判定，不會自動新增或結束接觸標記。

### 5. 送出標記

確認回合開始、接觸、結束與結果都正確後，按下 `Enter` 送出。

送出後的標記會進入不可直接修改的狀態；如需修正，請建立修正草稿並重新送出。

## 快捷鍵總覽

| 按鍵      | 功能                  |
| --------- | --------------------- |
| `Z`       | 切換回合開始/結束邊界 |
| `X`       | 加入接觸標記          |
| `Space`   | 播放/暫停影片         |
| `<`       | 選擇左方結果          |
| `>`       | 選擇右方結果          |
| `?`       | 記錄未知結果          |
| `Enter`   | 送出目前回合          |
| `←` / `→` | 前後移動畫格          |

## 標記狀態

| 顏色 | 狀態          | 說明                     |
| ---- | ------------- | ------------------------ |
| 灰色 | 草稿          | 目前正在編輯，尚未送出   |
| 黃色 | 已送出/處理中 | 標記已送出，系統正在處理 |
| 藍色 | AI 完成       | AI 分析已完成            |
| 綠色 | 身分對應完成  | 球員身分對應已完成       |

## 快速檢查

送出前請確認：

- 回合開始與結束順序正確
- 沒有把 `Z` 當成接觸事件
- 每個接觸球的瞬間都有按 `X`
- 左右結果或未知結果已選擇
- 目前畫面確實是要送出的回合

## 第一次使用時的提示文案

> 先播放影片找到回合開始，按 `Z` 開始標記。球員每次接觸球時按 `X`，回合結束時再按 `Z`。最後用 `<`、`>` 或 `?` 選擇結果，確認無誤後按 `Enter` 送出。

## 重新查看教學

在標記控制列點選「操作教學」即可重新開啟本說明。教學視窗不會改變目前影片位置、選取的回合或正在編輯的草稿。
