# ADR-0001: GraphQL / REST / WebSocket / FlatBuffers boundaries

Status: Accepted by scaffold; primary agent must reconfirm during Phase 0.

- GraphQL: structured domain query/mutation.
- REST: media, binary, AI provider/callback, health.
- WebSocket: annotation command/revision/presence/status.
- FlatBuffers: per-frame overlay only.

Do not add a second overlapping transport without a new ADR.
